    How DropScore reads a video

    01

    Find the keyboard

    Locate the keybed strip, then fit the 88-key grid from the black-key pattern so every x-position maps to a MIDI pitch.

    02

    Track the tiles

    Segment falling rectangles by colour and motion, follow them frame to frame, and read their height as note duration.

    03

    Convert to time

    Estimate the fall speed in pixels per second and turn each strike-line crossing into a precise note onset.

    04

    Engrave

    Quantize onsets to a detected tempo grid, split hands, spell accidentals against the key, and emit MIDI / MusicXML.
